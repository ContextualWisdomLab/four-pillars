# Figma Product Design

The editable product UI, report detail, foundations, and architecture visualization are maintained in the Figma file:

https://www.figma.com/design/ft8YLTIY53U4FtNkkC8wpY

## Pages

- `00 · Foundations` — color, typography, spacing, A4 report grid, and Korean copy standards.
- `01 · Product UI` — report creation, calculation review, job state, and download flows.
- `02 · Report Detail` — searchable report hierarchy and balanced opportunity/caution/action components.
- `03 · Architecture` — deterministic calculation, NIM, quality gate, renderer, queue, and artifact boundaries.

The software source treats the Figma file as a product and communication artifact rather than a calculation source of truth. UI changes must preserve visible calculation fingerprints, boundary warnings, job state, accessible text hierarchy, and the distinction between symbolic interpretation and practical techniques.
