# Four Pillars

Four Pillars provides deterministic Korean Four Pillars (사주·만세력) calculation and schema-validated AI-assisted report generation while keeping calendar calculation and interpretation on separate trust boundaries.

## Product boundary

The calculation engine owns deterministic calendar and relationship facts. An explicitly selected interpretation backend may consume those facts as read-only evidence, but model output does not alter calculation truth. Report quality gates reject deterministic contradictions, vague or unsafe claims, and unsupported certainty before publication.

## Release and evidence boundary

A calculation result, model-generated report, passing test, source version, or open pull request is not by itself evidence of scientific prediction, production deployment, customer adoption, certification, or a published release. Repository-facing claims should remain bound to protected source and applicable release/deployment evidence.
