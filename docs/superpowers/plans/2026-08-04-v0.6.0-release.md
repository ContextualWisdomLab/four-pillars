# Four Pillars v0.6.0 Release Implementation Plan

**Goal:** Publish the Figma-backed browser report-history recovery workflow as Four Pillars v0.6.0 with aligned package, runtime, API, changelog, distribution, container, and GitHub Release surfaces.

**Architecture:** Preserve deterministic calculation, NVIDIA NIM interpretation, required MSA ports, optional report-history capability, durable cursor semantics, and all v0.5 privacy boundaries. Treat the responsive browser recovery surface as an additive minor release.

**Tech stack:** Python 3.11/3.12, FastAPI, static HTML/CSS/JavaScript, Pydantic 2, SQLite, Hatchling, pytest, coverage.py, Ruff, Docker, GitHub Actions.

## Constraints

- `NVIDIA_NIM_API_KEY` remains the only hosted interpretation credential.
- Statement and branch coverage remain exactly 100%.
- Every production public API retains a complete docstring.
- Database object names remain multi-word `snake_case`.
- Browser authentication state remains ephemeral and never enters a URL or persistent browser storage.
- Release notes follow Keep a Changelog and Semantic Versioning.

## Task 1: Lock the release contract

- Require package, runtime, FastAPI, and changelog version `0.6.0`.
- Require release notes to describe recent-report recovery, authenticated downloads, cursor pagination, stale-response protection, complete coverage, and the NVIDIA NIM credential boundary.
- Record the expected RED while production metadata remains at `0.5.0`.

## Task 2: Align release surfaces

- Advance `pyproject.toml` and `src/four_pillars/version.py` to `0.6.0`.
- Move browser-recovery notes from Unreleased into a dated `0.6.0` section.
- Preserve future PostgreSQL, object-storage, and golden-boundary work under Unreleased.
- Update release comparison links.

## Task 3: Verify, review, merge, and publish

- Run all Python 3.11/3.12, coverage, lint, docstring, document, prompt, security, distribution, and container gates.
- Resolve every current-head review finding.
- Merge only the exact green approved head.
- Confirm tag `v0.6.0`, wheel, source distribution, and `SHA256SUMS` publication.
